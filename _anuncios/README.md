# Canvas announcements (`_anuncios/`)

Dated Markdown files published to Canvas via Dauber.

## Naming convention

`YYYY-MM-DD-slug.md` (e.g., `2026-08-22-bienvenida.md`).

## Format

Each file becomes one announcement. The filename date sets the posting date; the slug is internal. Content is standard Markdown.

## Publishing

Use the `canvas-announcements` skill (if configured) or manually copy content into Canvas. Dauber reads `dauber/config.toml` for course credentials.
