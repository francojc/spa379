# Practice apps (`practica/`)

Standalone interactive tools (HTML apps, quizzes, etc.) embedded or linked from `practica.qmd`.

## Getting started

Create a subdirectory per app (e.g., `practica/vocabulario/`) with:
- `index.qmd` — course page embedding the app via iframe
- `app.html` — the standalone app

Add links from `practica.qmd` to each app's `index.qmd`.
