# Slides (`diapositivas/`)

Reveal.js presentations for in-class instruction.

## Naming convention

`diap-NN.qmd` where NN is the session number.

## Templates

- `_template.qmd` — minimal structure

## Rendering

The root page `diapositivas.qmd` auto-lists all slides. The schedule links to rendered slides as `./diapositivas/diap-NN.html`.

## Note

Slide `_metadata.yml` references `images/logo-wfu.jpg` — replace with your institution logo or remove the `logo:` line.
