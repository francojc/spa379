# Lesson Plans (`planes/`)

Detailed plans for each class session.

## Naming convention

`plan-NN.qmd` where NN is the zero-padded session number (e.g., `plan-01.qmd`).

## Getting started

Copy `_template.qmd` and fill in objectives, activities, and timing.

## Rendering

The root page `planes.qmd` auto-lists all files in this directory via Quarto's `listing:` feature. The schedule (`_data/horario.csv`) links to rendered plans as `./planes/plan-NN.html`.
