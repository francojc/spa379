# Grammar articles (`gramatica/`)

Grammar explanations and practice articles.

## Naming convention

`gram-NN.qmd` where NN corresponds to the chapter/unit number.

## Getting started

Copy `_template.qmd`. Add title, description, explanation with examples, and practice activities.

## Rendering

The root page `gramatica.qmd` auto-lists all articles, sorted by `subtitle` (chapter label).
